日期是预测，不是承诺；延期时改这里并在 `note/decisions.md` 记原因，不悄悄挪。

**怎么在 5 天内做完：** M0 定下数据模型和协议类型后，三条线并行，各自在独立的 worktree 里由 Codex 实现：
- 线 A：同步核心（iCal + 本地快照夹具 → 模型 → 变化事件 → 账本）
- 线 B：agent 协议（CLI + MCP）和写入关口
- 线 C：界面（先接假数据，再接协议）

**风险项（拖了不阻塞其他线）：** Canvas / Ed 浏览器取数（统一登录可能要求多因素认证；只能在用户电脑上用真实登录态迭代）；Notion 令牌和 Hermes 配置需要用户操作。

## 第二版：主动带你复习（2026 年 12 月 – 2027 年 1 月）

- **考前复习 agent**：老师发了模拟卷、复习资料时，自动归档到对应课程；临近考试时，按考试范围、你的薄弱点（分数低的考核项、拖延过的任务）排复习计划，由 agent 整理复习清单、出练习题，每条都带原文出处。
- **自我修复的抓取脚本**：校验失败时由 Codex 经 Playwright MCP 修复脚本，修复快照沉淀为回归测试。
- **尽量少改动的重排**；学习个人节奏（预计和实际用时的偏差）。

## 第三版：作业工人（2027 年 2 月，S1 开学前）

- 按单项作业授权自主等级：L0 只读 / L1 辅助（讲解、查资料）/ L2 起草（给草稿你来改）/ L3 代做部分（你确认后才算完成）。**不做 L4 自动提交。**
- 授权依据由你填写（例如这门课允许使用 AI 的范围），全程审计日志。
- 规划、执行、验证分离：DeepSeek 规划 → Codex / Claude Code 在沙箱里执行 → 三层验收（可执行检查 → 评分标准覆盖检查 → 你把关）。

状态只用：未开始 / 进行中 / 已完成 / 已搁置。
