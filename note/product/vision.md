# 产品愿景

- **这是什么：** 以课业为核心的个人行动中心。墨大的 Canvas、Ed、iCal 自动接入，学校之外的事（找实习、游戏等）按模块手动管理，统一排进每周计划。
- **给谁用：** 首先是我自己（墨大学生，同时在找实习）；之后是同样不能自建 Canvas 令牌的墨大同学。
- **要解决的核心问题：** 课程信息分散在 Canvas 和 Ed；作业、权重、截止时间靠手动抄进 Excel；截止时间被改了发现不了；每天做什么靠脑子排；分数要自己算。
- **三个优点（决策 #26）：**
  1. **自动**：作业、权重、日期、分数自己长出来、自己更新，有变化主动提醒。
  2. **可信**：拆出的每一步都附原文出处，逐字核对过。
  3. **排得动**：截止时间加上各模块每周的时间预算，排成每周计划。另附成绩推算。
- **成功长什么样：** 下学期我不再手动做那张 Excel。辅助指标：同步成功率、抽取准确率（用自己标注的评估集测）、预计和实际用时的偏差。

## 明确不做

- 不做笔记或知识库编辑（Notion 只读集成，决策 #27）。
- 不做聊天机器人；推理交给外部 agent（决策 #13）。
- 不自动提交作业（不做 L4）。
- 不做多用户线上服务；数据只留在本机。
